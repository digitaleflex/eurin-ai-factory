# Pattern Catalog

This directory converts external engineering observations into explicit, traceable patterns for Eurin AI Factory.

## Source hierarchy

1. `rules/MASTER_RULES.md`
2. Factory architecture and approved decisions
3. Agent contracts
4. Skills and templates
5. External references
6. Experimental observations

External repositories never override Factory rules.

## Current catalogs

- [Melvynx Pattern Catalog](./melvynx-catalog.md)
- [Engineering Patterns](../engineering-patterns/README.md)

## Pattern lifecycle

`OBSERVED → ANALYZED → CANDIDATE → PROTOTYPED → ADOPTED | DEFERRED | REJECTED`

Adoption requires a Factory Decision Gate. Architectural changes also require an ADR or decision-log entry.
