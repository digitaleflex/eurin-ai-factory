# Eurin AI Factory — References

Cette section rassemble des références externes utilisées pour étudier des patterns d'ingénierie, d'agents, de skills, de CLI et de tooling.

Une référence n'est pas une source de vérité pour la Factory.

Elle sert à :
- observer des patterns ;
- comparer des approches ;
- identifier des idées réutilisables ;
- documenter ce que nous adoptons ou rejetons ;
- éviter de reproduire aveuglément une architecture externe.

## Règle

**INSPIRATION ≠ DÉCISION D'ARCHITECTURE**

Toute adoption réelle doit passer par les règles, contraintes et Decision Gates de la Factory.
