# Eurin AI Factory

> Système personnel de production logicielle assistée par IA : idées → produits → impact.

## Architecture documentaire

```text
eurin-ai-factory/
├── agents/       # rôles opérationnels
├── rules/        # constitution et règles
├── skills/       # connaissances spécialisées réutilisables
├── templates/    # formats d'artefacts
├── orchestration/ # workflows, gates et handoffs
├── docs/         # modèles de compréhension et documentation
├── memory/       # décisions, patterns, leçons
└── examples/     # exemples de projets
```

## Pipeline

**Product → Architect → Developer → QA → Delivery → Feedback → Memory**

## Modèle de compréhension

Avant de construire, la Factory peut examiner un projet selon plusieurs vues :

1. Produit
2. Domaine
3. Système
4. Données
5. Comportement
6. Infrastructure
7. Sécurité / Risques
8. Opérations
9. Qualité
10. Apprentissage

> L'IA produit. Eurin décide.
