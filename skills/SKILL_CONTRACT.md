# Skill Contract

Chaque Skill de la Factory doit respecter ce contrat.

## 1. Purpose

Décrire précisément le problème que le Skill permet de résoudre.

## 2. Activation

Décrire quand le Skill doit être chargé.

## 3. Non-Activation

Décrire quand il ne doit pas être chargé.

## 4. Required Context

Lister les informations nécessaires avant utilisation.

## 5. Method

Décrire la méthode de travail étape par étape.

## 6. Outputs

Lister les artefacts ou décisions attendus.

## 7. Validation

Définir comment vérifier que le Skill a été correctement appliqué.

## 8. Security

Identifier les contraintes de sécurité spécifiques.

## 9. Failure Modes

Documenter les erreurs ou mauvaises utilisations fréquentes.

## 10. Escalation

Indiquer quand l'agent doit arrêter et demander une décision.

## 11. Reuse

Identifier ce qui peut devenir Rule, Template, Pattern ou Starter Kit.

## Principe

Un Skill doit aider l'agent à prendre de meilleures décisions et non simplement lui fournir une liste de commandes.
