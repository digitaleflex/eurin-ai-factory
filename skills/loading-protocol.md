# Skill Loading Protocol

## Étape 1 — Identifier la tâche

Déterminer le résultat attendu avant de choisir un Skill.

## Étape 2 — Identifier le risque

Évaluer le blast radius.

## Étape 3 — Sélectionner les Skills

Charger le minimum suffisant.

## Étape 4 — Vérifier les dépendances

Exemple :

`Migration DB` → PostgreSQL + Testing + Deployment

## Étape 5 — Appliquer les Rules

Les Rules de la Factory restent prioritaires.

## Étape 6 — Produire

Appliquer la méthode du Skill.

## Étape 7 — Valider

Utiliser les validations prévues.

## Étape 8 — Capitaliser

Si un problème récurrent est découvert :

```text
Problème
   ↓
Pattern
   ↓
Skill / Rule / Template
   ↓
Réutilisation
```
