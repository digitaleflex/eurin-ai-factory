# Decisions

Répertoire des décisions validées de la Factory.

Format recommandé : YYYY-MM-DD-short-title.md

Chaque décision doit indiquer :
- contexte ;
- problème ;
- options ;
- décision ;
- raisons ;
- conséquences ;
- statut ;
- date de révision éventuelle.

Une décision ne doit pas être copiée comme règle générale sans preuve qu'elle est réutilisable.
