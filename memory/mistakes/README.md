# Mistakes

Répertoire des erreurs significatives.

Chaque erreur doit chercher un mécanisme de prévention, pas seulement documenter le symptôme.

Format recommandé :
- contexte ;
- erreur ;
- impact ;
- cause ;
- détection ;
- prévention ;
- règle / skill / template / test créé ou modifié ;
- statut.
