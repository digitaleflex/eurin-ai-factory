## Convention

Les diagrammes utilisent Mermaid lorsque possible afin de rester versionnables, lisibles dans GitHub et modifiables par les agents.

## Couleurs conceptuelles

- Bleu : contexte / entrée
- Vert : produit / validation positive
- Violet : architecture / structure
- Orange : développement / transformation
- Rouge : qualité / risque / blocage
- Jaune : feedback / apprentissage
- Cyan : infrastructure / delivery

Les couleurs restent secondaires : la structure et les relations doivent rester compréhensibles sans elles.
