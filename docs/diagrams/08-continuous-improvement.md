# 08 — Continuous Improvement Loop

```
flowchart LR
    BUILD[Build] --> MEASURE[Measure]
    MEASURE --> FEEDBACK[Feedback]
    FEEDBACK --> LEARN[Learn]
    LEARN --> IMPROVE[Improve Rules / Skills / Templates]
    IMPROVE --> BUILD
```

## Boucle

1. Produire
2. Mesurer
3. Observer les erreurs et frictions
4. Extraire les leçons
5. Transformer les leçons en actifs réutilisables
6. Réutiliser sur le prochain projet
