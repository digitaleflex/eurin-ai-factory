# Modèles décisionnels

## Decision Table

À utiliser lorsque plusieurs conditions produisent plusieurs résultats.

Colonnes recommandées :

- conditions ;
- combinaison ;
- action ;
- priorité ;
- exception.

## Decision Tree

À utiliser lorsque les décisions sont principalement séquentielles.

## ADR

Une Architecture Decision Record doit expliquer :

1. Context
2. Decision
3. Alternatives
4. Consequences
5. Status

## Risk Matrix

Documenter :

- risque ;
- probabilité ;
- impact ;
- blast radius ;
- mitigation ;
- owner ;
- status.

## Règle

Une décision importante doit être traçable. L'agent ne doit pas seulement produire le résultat ; il doit pouvoir expliquer pourquoi la décision a été prise.
