# Diagram Selection Matrix

Utiliser cette matrice pour choisir rapidement le bon modèle.

| Si la question est... | Modèle |
|---|---|
| Pourquoi ce produit existe-t-il ? | Product Spec |
| Qui utilise quoi ? | Use Case |
| Quelles sont les frontières du système ? | C4 Context |
| Quels sont les grands composants ? | C4 Container |
| Comment un composant est-il organisé ? | C4 Component |
| Quelles données existent ? | Conceptual Data Model |
| Comment les données sont-elles reliées ? | ERD |
| Comment seront-elles stockées ? | Physical Data Model |
| Comment une donnée circule-t-elle ? | Data Flow |
| Qui appelle qui ? | Sequence Diagram |
| Quel est le cycle de vie d'un objet ? | State Machine |
| Quelle décision dépend de plusieurs conditions ? | Decision Table |
| Quelle infrastructure est nécessaire ? | Deployment Diagram |
| Quelle décision technique a été prise ? | ADR |
| Quel risque peut bloquer le projet ? | Risk Matrix |
| Comment vérifier le résultat ? | Test Model / QA Report |
