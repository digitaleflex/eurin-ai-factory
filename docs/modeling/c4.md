# C4 Modeling

## Niveau 1 — Context

Montre :

- utilisateurs ;
- systèmes externes ;
- système étudié.

Question : **où sommes-nous ?**

## Niveau 2 — Container

Montre les grands blocs exécutables ou stockages.

Question : **quels sont les grands composants ?**

## Niveau 3 — Component

Montre les composants internes d'un container.

Question : **comment ce composant est-il organisé ?**

## Niveau 4 — Code

Utiliser seulement si le niveau de détail apporte une vraie valeur.

Question : **comment l'implémentation concrète est-elle structurée ?**

## Règle

Commencer au niveau le plus haut nécessaire et descendre seulement lorsqu'une décision l'exige.
