# Orchestration Metrics

La couche d'orchestration mesure le fonctionnement de la Factory, pas seulement la vitesse.

## Métriques V1

- workflow completion rate ;
- handoff rejection rate ;
- agent rework rate ;
- human intervention time ;
- blocked workflow count ;
- Decision Gate escalation rate ;
- QA defect discovery rate ;
- rollback frequency ;
- reusable assets created ;
- cost per workflow.

## Règle d'interprétation

Une réduction du temps n'est pas une amélioration si elle augmente les défauts, les régressions, le risque ou l'intervention humaine nécessaire.

Les métriques servent à améliorer la Factory et ne doivent pas devenir des objectifs isolés à optimiser au détriment de la qualité.
