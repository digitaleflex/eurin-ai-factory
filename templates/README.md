# Templates — Eurin AI Factory

Les templates standardisent les artefacts produits par les agents.

## Templates prévus

- Product Spec
- Architecture Spec
- ADR
- Data Model
- API Contract
- Sequence Diagram
- State Machine
- Decision Table
- QA Report
- Risk Register
- Agent Handoff
- Project README

## Règle

Un template doit réduire le travail répétitif sans empêcher le raisonnement.

Un template n'est pas une vérité métier : il fournit une structure.
